## Findings from the surveys

| Finding                                                 | Evidence and disposition                                                                                                                                                                                                                                                                |
| ------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| OpenAI catalog ownership                                | The native provider read its default from the compatible provider module. The old direction was confirmed. The new catalog supplies the default directly to both paths.                                                                                                                 |
| Modes rules state                                       | The survey correctly found no display of `hasRulesToExport`. The effect reads it as a cache to avoid repeat rules checks for a mode. The state and message exchange stay in the view.                                                                                                   |
| Native MCP feedback differs from ordinary tool feedback | The ordinary path reads and acknowledges `queuedMessageId`. The native MCP path records text feedback with `say`. This is a candidate behavior fix with high confidence in the difference and medium confidence in its impact. Route it to a focused tool approval repair.              |
| MCP watcher suppression spans both scopes               | `debounceConfigChange` reads one `isProgrammaticUpdate` flag while settings writes reset it on a timer. `deleteServer` writes through a separate path. A missed external update or redundant refresh remains possible. Route this medium-risk ordering issue to an MCP settings repair. |
| SSE sets a process-wide EventSource                     | The SSE constructor path installs `ReconnectingEventSource` on `global.EventSource`. Its effect on other consumers has no direct test in the selected suites. Route any change to a transport-specific repair.                                                                          |
| Task history watch timer can outlive disposal           | `startWatcher` owns a local debounce timer. `dispose` closes the watcher and cancels the periodic timer. The separate debounce remains a lifecycle repair candidate of low to medium severity.                                                                                          |
| Skill descriptions use interpolated frontmatter         | `createSkill` inserts the trimmed description into YAML as text. Descriptions with YAML punctuation or line breaks can change how the document parses. Route this medium-risk issue to a skill creation repair.                                                                         |
| Skill watcher listener ownership needs evidence         | The watcher disposes the VS Code watcher but does not separately store returned listener disposables. The survey's leak claim requires verification against actual VS Code disposal behavior.                                                                                           |
